# ПОС — преподавательская оценка студентов

Консольное приложение на Go для ведения рубрикатора, выставления оценок и расчёта итогов по одному курсу.

## Запуск

Нужен Go 1.22 или новее. Из корня проекта:

```powershell
go run ./cmd/pos
go test ./...
```

Данные сохраняются в `data/pos.json`. Для отдельного запуска с другим набором данных передайте путь:

```powershell
go run ./cmd/pos -data data/demo.json
```

## Демонстрация

| Команда | Что ввести |
|---|---|
| `1` | ID `anna`, имя `Анна` |
| `2` | `Содержание`, максимум `10`, вес `3` |
| `2` | `Оформление`, максимум `5`, вес `1` |
| `4` | `anna`, `Содержание`, `12`. Программа сообщит об ошибке |
| `4` | `anna`, `Содержание`, `8` |
| `4` | `anna`, `Оформление`, `2` |
| `7` | `anna`. Итог по весам — 70,00% |
| `8` | `anna`, затем путь к новому файлу, например `anna-report.csv` |

Команда `4` обновляет оценку, если у этого студента уже есть оценка по выбранному критерию. Команда `6` её отменяет. Имена критериев уникальны в рубрикаторе, а ID студентов задаёт преподаватель. У двух студентов может быть одинаковое имя.

Итог считается из текущих оценок и рубрикатора. Для каждого критерия балл делится на максимум. Полученные доли умножаются на веса критериев, суммируются и делятся на сумму весов. Результат выражается в процентах. Если по одному из критериев ещё нет оценки, программа перечисляет недостающие критерии.

Команда `8` создаёт новый JSON- или CSV-файл с итогом выбранного студента.

## Архитектура

Выбрана **Ports and Adapters**. Зависимости пакетов направлены внутрь:

```text
console ────────────────→ application ──→ domain
jsonstore ──────────────→ application и domain
gradefiles ─────────────→ application
cmd/pos ────────────────→ application и адаптеры
```

- `internal/domain` содержит модель, проверку оценок и расчёт итога.
- `internal/application` содержит сценарии и выходные порты `Repository` и `ReportExporter`.
- `internal/adapters/console` разбирает команды и отображает результат. `jsonstore` читает и сохраняет состояние курса. `gradefiles` формирует отчёт. Файловые адаптеры преобразуют данные на границах приложения.
- `cmd/pos` — composition root. Контейнер [Uber Dig](https://pkg.go.dev/go.uber.org/dig) получает конструкторы, связывает адаптеры с портами, собирает фасад и запускает меню.

Репозиторий загружает данные один раз при запуске. Изменения проверяются на копии состояния, записываются через временный файл и только затем публикуются в памяти. Файл данных рассчитан на один запущенный экземпляр программы. Если в JSON вручную испортили критерий, программа показывает предупреждение о критерии и связанных оценках. Такие записи сохраняются при других изменениях, а итог доступен после исправления критерия в файле и перезапуска.

## Карта DDD

| Принцип | Где в проекте |
|---|---|
| Единый язык | `Student` — студент, `Rubric` — рубрикатор, `Criterion` — критерий, `Evaluation` — выставленная оценка, `Score` — балл |
| Entity | `Student` определяется ID. У `Evaluation` ключ — ID студента и имя критерия |
| Value Object | `Score` определяется числом баллов. После изменения балла фабрика создаёт новое значение |
| Границы | `Rubric` владеет картой критериев и следит за уникальностью имён. Оценки хранятся отдельно и ссылаются на студента и критерий |
| Инварианты | Максимум и вес критерия положительны. Оценка выставляется по критерию из рубрикатора, балл лежит в диапазоне от нуля до максимума |
| Repository | Порт `application.Repository` предоставляет снимок курса и сохраняет его изменения. Файловая реализация находится в адаптере |
| Domain Service | `domain.CalculateTotal` проверяет полноту оценок и рассчитывает взвешенный итог |

## Паттерны GoF

| Группа | Паттерн | Какую задачу решает |
|---|---|---|
| Порождающий | **Factory**, `domain.NewEvaluation` | Применяет одни и те же проверки при ручном вводе и загрузке данных |
| Структурный | **Facade**, `application.Service` | Даёт меню единый вход в операции. Меню вызывает выставление, расчёт и экспорт через фасад |
| Поведенческий | **Command**, `console.command` | Связывает пункт меню с выполняемой функцией. Меню одинаково запускает любое выбранное действие |
